How updates are applied
  • Each field is mapped to the original PDF locations; employee and representative names, employer details, and selected terms update wherever they repeat.
  • Each save starts from the untouched source PDFs, so repeated edits do not stack over old output.
  • Cross-document bulk apply is optional. Use it only when one identical value should replace the document-specific values in multiple agreements.
  • Some source values are in bold black text rather than yellow highlight. Only the AFGO source has actual yellow highlights; those are retained around the corresponding edited values.
  • ASIA and DNB contain an employer-name mismatch in the original signature block. The editor flags it and leaves it unlinked until you choose to synchronize it.
